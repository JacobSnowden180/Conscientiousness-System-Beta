# Conscientiousness System Beta

A static page for planning a day the night before. The schedule is a small spreadsheet on a yellow legal pad. You type tasks and times yourself, or answer a short guided setup and drop the suggested tasks onto the grid.

Task and time are separate columns. Dragging a task reorders only tasks. Dragging a time reorders only times. A task lines up with whatever time ends up in its row. The page does not save anything. Refreshing starts over.

## Run it

Open `index.html` in a browser. There is no install, no build, and no server. The same files work on GitHub Pages from the repository root.

`about.html` is a short placeholder for the “Read about” link.
